# Adam Van Vranken — personal portfolio

Static, responsive portfolio for https://adamvv303.github.io.

## Publish
In Settings → Pages, select Deploy from a branch, main, /(root), then Save.

## Edit
Pages are plain HTML, each in its own directory. Shared styling is in assets/style.css. No build or package installation is required. Keep page titles, descriptions, canonical URLs, and sitemap.xml in sync when adding pages.
